## 一、项目总览

### 1.1 游戏定位
**类型**: Roguelite 弹幕射击游戏（Bullet Hell / Vampire Survivors 类）

**核心循环**: 战斗 → 击杀 → 获得资源 → 升级/购买 → 更强战斗

### 2.2 单局游戏时间线

## 三、系统详细拆解

### 3.1 武器系统

#### 数据结构
```typescript
interface WeaponConfig {
  id: WeaponType;           // 'pistol' | 'smg' | 'sniper' | 'shotgun' | 'rpg'
  name: string;
  damage: number;           // 基础伤害
  fireRate: number;         // 射击间隔(ms)
  magazineSize: number;     // 弹夹容量
  bulletRange: number;      // 子弹射程(px)
  bulletSpeed: number;      // 子弹速度
  critRate: number;         // 暴击率(0~1)
  playerSpeedBonus: number; // 装备移速加成(可负)
  isLongGun: boolean;       // 是否长枪(影响绘制偏移)
}
```

#### 5种武器对比

| 武器 | 伤害 | 射速 | 弹夹 | 射程 | 特性 | 定位 |
|------|------|------|------|------|------|------|
| 手枪 | 10 | 400ms | 12 | 400px | +0.5移速 | 平衡型/初始 |
| 冲锋枪 | 8 | 100ms | 30 | 350px | 高射速 | 弹幕压制 |
| 狙击枪 | 50 | 1200ms | 5 | 700px | 自带穿透+1, -0.3移速 | 高伤单体 |
| 散弹枪 | 8×6 | 800ms | 6 | 250px | 6发散弹, -0.2移速 | 近战爆发 |
| 火箭筒 | 84 | 2000ms | 1 | 500px | 爆炸100px范围, -0.3移速 | AOE清场 |

#### 切换机制
- **触发方式**: 鼠标滚轮 / 点击按钮
- **动画时长**: 1秒（圆弧旋转动画）
- **限制**: 切换期间无法射击
- **弹药保存**: 切换时保存当前弹药状态

#### 设计亮点
- 多武器共存机制（非替换）
- 每把武器独立弹药记录
- 滚轮切换 + UI按钮双入口

### 3.2 怪物系统

#### 怪物类型配置

| 类型 | 名称 | 血量 | 速度 | 伤害 | 掉落金币 | 特殊 |
|------|------|------|------|------|---------|------|
| 1 | 普通怪 | 30×L | 1.5×倍率 | 10 | 3 | 基础敌人 |
| 2 | 快速怪 | 20×L | 2.5×倍率 | 8 | 2 | 高速低血 |
| 3 | 重甲怪 | 80×L | 0.8×倍率 | 20 | 8 | 高血低速 |
| 4 | 远程怪 | 25×L | 1.2×倍率 | 12 | 5 | 可发射子弹 |
| 5 | 史莱姆王(Boss) | 500×L^1.5 | 1.0 | 50 | 100 | 30杀后出现 |

#### 生成机制
```typescript
// 权重随机生成
// 总权重 = 各类型权重之和
// 随机数落在哪个区间就生成对应怪物
// 每关血量倍率 = 1 + (level-1) * 0.15
// Boss: level >= 3 且 kills >= 30
```

#### AI行为
- **基础追踪**: 向玩家位置直线移动
- **远程攻击**: Type4怪物可发射EnemyBullet
- **碰撞伤害**: 接触玩家造成伤害

### 3.3 Buff系统（特殊能力）

#### 8种Buff一览

| Buff ID | 名称 | 触发方式 | 效果 | 价格公式 |
|---------|------|---------|------|---------|
| `fireBuff` | 引火 | 命中概率点燃 | 持续火焰伤害 | 20+15L |
| `poisonBuff` | 淬毒 | 命中概率中毒 | 中毒+毒圈DOT | 20+15L |
| `energyAura` | 能量气场 | 被动光环 | 范围内持续伤害 | 25+20L |
| `executionBuff` | 处决 | 低血量敌人额外伤害 | <25%血量2x伤害 | 10+L² |
| `criticalRage` | 暴怒 | 暴击触发 | 范围AOE伤害 | 25+1.5L |
| `vampire` | 吸血 | 击杀回复 | 伤害5%转生命 | 10+2L |
| `ammoSupply` | 弹药补充 | 击杀概率补充 | 回满当前弹夹 | 10+2L |
| `desperateFight` | 险中取胜 | 血量越低伤害越高 | 1血时2x伤害 | 20+3L |

#### DOT类Buff实现细节

**引火(Fire)**:
- 触发概率: 基础20% + 5%×等级
- 持续时间: 3000ms + 500ms×等级
- 每秒伤害: 3 + 1×等级
- 叠加上限: 3层

**淬毒(Poison)**:
- 触发概率: 基础20% + 5%×等级
- 持续时间: 5000ms + 1000ms×等级
- 每秒伤害: 2 + 1×等级
- **独有特性**: 死亡留下毒圈(半径80px, 持续5s)
- 毒圈对进入的敌人造成中毒

### 3.4 成长链系统（Growth Chain）

#### 设计理念
> "获得基础Buff后，解锁进阶升级路径，形成一环套一环的成长感"

#### 结构示意
```
Tier 1 (初级)          Tier 2 (中级)              Tier 3 (高级)
┌─────────┐           ┌──────────────────┐       ┌─────────────┐
│毒圈扩大I │           │剧毒II             │       │             │
│毒性增强I │───2选1──▶│传染II             │──2选2─▶│剧毒吸收I    │
│         │           │毒圈扩大II         │       │             │
│         │           │剧毒III            │       │             │
└─────────┘           └──────────────────┘       └─────────────┘
     ↑                       ↑                         ↑
  拥有淬毒              1个Tier1节点              2个Tier2节点
```

#### 解锁规则
| 段位 | 解锁条件 | 示例 |
|------|---------|------|
| Tier 1 | 拥有对应基础Buff | 有淬毒→可买毒圈扩大I/毒性增强I |
| Tier 2 | 至少拥有1个Tier1节点 | 有毒圈扩大I→可买剧毒II等 |
| Tier 3 | 至少拥有2个Tier2节点 | 有2个T2节点→可买剧毒吸收I |

#### 淬毒成长链7节点详情

| 节点 | 段位 | 效果 |
|------|------|------|
| 毒圈扩大I | T1 | 毒圈范围+30% |
| 毒性增强I | T1 | 伤害+30%, 持续+2s |
| 剧毒II | T2 | 10%真实伤害(Boss为1%) |
| 传染II | T2 | 20%概率传染100px内敌人 |
| 毒圈扩大II | T2 | 范围+20%, 持续+30% |
| 剧毒III | T2 | 伤害频率1s→0.7s |
| 剧毒吸收I | T3 | 站在毒圈上回血2HP/s |

| 来源 | 数量 | 说明 |

#### 金币消耗
| 消耗项 | 价格范围 | 说明 |
|--------|---------|------|

#### 设计特点
- **无上限经济**: 金币可以无限积累

- **策略选择**: 升级属性 vs 买新武器 vs 买Buff

### 3.6 升级系统

#### 触发时机
每关卡完成后（所有敌人被消灭）

#### 选项生成规则
```typescript
// 从UPGRADES池中随机选取3个
// 排除已达到最大值的属性
// 包含: 基础属性(10种) + 武器相关(6种) + Buff(8种)
// 可花费金币刷新(最多3次)
```

#### 10种基础属性

| 属性 | 类型 | 最大值 | 每级效果 |
|------|------|--------|---------|
| 弹夹容量 | int | 无限 | +1 |
| 射速 | % | 无限 | 射速+30% |
| 伤害 | int | 无限 | +1 |
| 移动速度 | % | 5.0 | +10% |
| 换弹速度 | % | 无限 | 换弹时间减少 |
| 射程 | px | 800px | +15px |
| 生命上限 | int | 无限 | +5HP |
| 穿透力 | int | 5 | +1 |
| 子弹速度 | % | 无限 | +100% |
| 金币拾取范围 | % | 无限 | +100% |

### 3.7 商店系统

#### 开放时机
每关卡结束后、升级选择前（可选进入）

#### 商品池
- 基础属性升级（同升级系统）
- 新武器购买（未拥有的武器）
- 武器等级提升
- 特殊Buff购买
- **锁定机制**: 某些商品需要先购买前置商品才能解锁

#### 显示数量
每次显示4个商品

### 3.8 关卡系统

#### 关卡进度
- **最大关卡**: 20关
- **难度递增**: 
  - 怪物血量: ×(1 + (level-1)×0.15)
  - 怪物数量: 逐渐增加
  - Boss: Level≥3且击杀数≥30时出现

#### 关卡流程
```
Level N 开始 → 生成怪物波次 → 全部消灭 → [可选:商店] → 升级选择 → Level N+1
```

### 3.9 音效系统

#### 实现方式: Web Audio API 合成

| 音效 | 类型 | 触发场景 |
|------|------|---------|
| shoot | 合成 | 玩家射击 (三层合成:噪声+低频+泛音) |

| game_over | TTS语音 | 游戏结束 ("游戏结束!") |

#### BGM结构
- **旋律层**: 方波主旋律 (32音符循环)
- **低音层**: 方波低音 (每4拍一次)
- **鼓点层**: 底鼓+军鼓+踩镲

## 五、设计亮点分析

### 5.1 做得好的地方

1. **成长链设计**
   - 创新的"一环套一环"升级路径
   - 给予玩家明确的长线目标
   - 增加Build多样性

2. **多武器共存**
   - 非替换式武器获取
   - 滚轮快速切换
   - 每武器独立弹药管理

3. **丰富的战术选择**
   - 8种Buff × 成长链 = 大量组合可能
   - 商店+升级双通道获取
   - 锁定机制增加策略深度

4. **视觉反馈完善**
   - 武器切换旋转动画
   - 伤害数字飘字
   - 金币拖尾粒子
   - 爆炸/烟雾特效
   - 后坐力系统

5. **音频体验**
   - Web Audio API实时合成（无需外部资源）
   - 8-bit风格BGM
   - 中文TTS语音提示

### 5.2 可优化点

1. **代码组织**
   - 10,000+行单文件，维护困难
   - 建议: 拆分为模块化文件

2. **性能**
   - Canvas渲染在requestAnimationFrame中
   - 大量状态更新可能导致不必要的重渲染
   - 建议: 使用useReducer或状态管理库

3. **平衡性**
   - 部分Buff强度差异明显
   - 火箭筒伤害84可能偏高(爆炸AOE)
   - 建议: 更多playtest数据支撑

## 八、总结

本项目是一个**功能完整的Roguelite射击游戏原型**，核心玩法循环清晰，系统丰富度较高。特别是**成长链系统**的设计具有创新性，为玩家提供了明确的长期追求目标。

**最值得继续深挖的方向**:
1. 完善其他Buff的成长链（目前仅淬毒完整）
2. 代码重构以支持更大规模开发
3. 存档系统提升留存
4. 更多武器和怪物种类

**潜在风险**:
- 单文件10,000+行的可维护性问题
- 部分数值未经充分playtest验证
- 缺少存档导致单局时间过长
