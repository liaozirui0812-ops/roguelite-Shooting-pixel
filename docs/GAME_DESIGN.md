## 一、现有功能总结

### 1. 核心玩法

| 功能模块 | 详细说明 |
|---------|---------|
| **游戏模式** | 俯视角2D射击生存，共5关，第5关为BOSS关 |
| **操作方式** | WASD移动 + 鼠标瞄准 + 左键射击 + 自动射击支持 |
| **胜利条件** | 击败第5关BOSS（史莱姆王） |

### 2. 玩家系统

| 属性 | 初始值 | 成长方式 | 最大值 |
|-----|--------|---------|--------|
| 生命值 | 20 | 升级/商店 | 无硬上限 |
| 伤害 | 4 | 升级/商店/武器 | 无硬上限 |
| 射速 | 360ms | 升级/商店 | 50ms |
| 移动速度 | 2.0 | 升级/商店 | 7.0 |
| 暴击率 | 20% | 升级/商店 | 软上限90% |
| 暴击伤害 | 150% | 升级/商店 | 软上限225% |
| 穿透力 | 0 | 升级/商店 | 15 |
| 射程 | 800 | 升级/商店 | 2000 |
| 弹夹容量 | 12 | 升级/商店 | 无硬上限 |
| 换弹速度 | 3000ms | 升级/商店 | 250ms |

**软上限机制**：
- 暴击率：70%以下100%收益，70%-110%超出部分50%收益，硬上限90%
- 暴击伤害：额外加成150%以下100%收益，超出部分50%收益

### 3. 武器系统

| 武器 | 伤害 | 射速 | 射程 | 弹夹 | 特点 |
|-----|------|------|------|------|------|
| 手枪 | 5 | 300ms | 800 | 12 | 基础武器，平衡型 |
| 霰弹枪 | 15×5 | 800ms | 300 | 7 | 近战爆发，散布角度17° |
| 狙击枪 | 50 | 1200ms | 1500 | 8 | 远程高伤，自带1穿透 |
| 冲锋枪 | 6 | 80ms | 400 | 30 | 高射速，低伤害 |
| 火箭筒 | 120 | 2000ms | 800 | 1 | 爆炸范围伤害，无暴击 |

### 4. 升级系统

**关卡完成奖励**：
- 每关完成提供3个随机升级选项
- 权重动态调整（根据关卡数）
- 支持刷新（每关1次）

**升级类型**：

| 类型 | 数值公式 | 权重公式 | 说明 |
|-----|---------|---------|------|
| 伤害加成 | +12%×(1+0.04L) | 100 | 贯穿全场 |
| 血量上限 | +⌊1+0.5L⌋ | max(10, 110-2L) | 前期保命 |
| 暴击率 | +4% | min(90, 30+2L) | 后期发力 |
| 暴击伤害 | +20%×(1+0.02L) | min(90, 30+2L) | 配合暴击率 |
| 射速提升 | +10% | 70 | 稳定收益 |
| 换弹速度 | +12% | 65 | 稳定收益 |
| 移动速度 | +0.1 | max(10, 75-L) | 后期稀释 |
| 弹夹容量 | +2 | 25+L | 逐渐重要 |
| 射程 | +0.15 | max(5, 45-L) | 前期有用 |
| 穿透力 | +1 | min(30, 6+1.2L) | 后期核心 |
| 生命回复 | +12+4L | max(20, 90-2L) | 前期容错 |
| 敌方减速 | -4%×(1+0.03L) | min(70, 20+2L) | 逐渐升高 |
| 金币奖励 | +10+4L | max(0, 30-1.5L) | 前期极高 |
| 武器升级 | +1级 | 50 | 稳健常青 |
| 子弹速度 | +10%×(1+0.03L) | max(10, 45-L) | 逐渐降低 |

### 5. 商店系统

- 关卡结束后进入商店
- 金币购买属性提升/武器
- 价格 = (基础价格 + 关卡系数 × 关卡数) × 数值
- 支持刷新（价格递增）和锁定功能
- 商品数值分档位随机

### 6. 敌人系统

| 类型 | 血量 | 伤害 | 速度 | 特点 |
|-----|------|------|------|------|
| 标准敌人 | 12 | 10 | 1.1 | 基础近战 |
| 中型敌人 | 25 | 15 | 0.6 | 较肉近战 |
| 大型敌人 | 70 | 30 | 0.35 | 高血高伤 |
| 远程敌人 | 25 | 5+2 | 0.7 | 可射击，5秒间隔 |
| BOSS史莱姆王 | 1200 | 10+13 | 1.1 | 多种攻击方式 |

**BOSS攻击方式**：
- 近战攻击：间隔1秒，伤害10
- 远程攻击：间隔5秒，3连发，伤害2
- 落地攻击：间隔7秒，锁定→跳跃→落地，伤害13，半径100

**分批生成机制**：
- 每批约25%敌人
- 15秒后或剩余30%时生成下一批

### 7. 掉落系统

| 掉落物 | 掉落条件 | 效果 |
|--------|---------|------|
| 金币 | 击杀敌人 | 1-3金币（基础） |
| 宝箱 | 击杀敌人（概率） | 3+⌊关卡/2⌋ 金币 |
| 武器升级箱 | 击杀敌人（概率） | 武器属性+随机提升 |
| 治疗瓶 | 受伤时概率提升 | 回复部分血量 |

**智能掉落**：
- 受伤越重，治疗瓶掉落概率越高
- BOSS掉落大量金币

### 8. 地图系统

- 世界大小：3000×3000
- 视口大小：1200×800
- 随机障碍物：20个
- 障碍物可阻挡移动和射击

### 9. 视觉效果

- 像素风格美术素材
- 玩家行走动画
- 敌人受击闪烁
- 子弹轨迹
- 爆炸效果（火箭弹）
- 烟雾效果
- 枪口火焰
- 伤害数字浮动
- 金币获取弹字

## 三、新系统设计方案

### 🌟 优先级 S - 核心体验提升

#### 1. 元素系统

**设计目标**：增加战斗策略深度，让武器选择更有意义

**元素类型**：

| 元素 | 效果 | 触发条件 | 持续时间 |
|-----|------|---------|---------|
| 🔥 火焰 | 持续燃烧伤害 | 火焰攻击命中 | 3秒 |
| ❄️ 冰冻 | 减速50% | 冰冻攻击命中 | 2秒 |
| ⚡ 雷电 | 连锁电击（跳3个敌人） | 雷电攻击命中 | 即时 |
| ☠️ 毒素 | 持续毒素伤害+减防 | 毒素攻击命中 | 5秒 |
| 💫 虚空 | 吸引周围敌人 | 虚空攻击命中 | 1秒 |

**元素反应**：
- 火焰 + 冰冻 = 蒸汽爆发（额外伤害）
- 雷电 + 毒素 = 腐蚀闪电（范围持续伤害）
- 冰冻 + 雷电 = 冻结闪电（禁锢敌人）

**实现方式**：
- 武器附带元素属性
- 升级可获得元素附魔
- 敌人有元素抗性/弱点

```
数据结构：
interface ElementalEffect {
  type: 'fire' | 'ice' | 'lightning' | 'poison' | 'void';
  duration: number;
  damage: number;
  stackable: boolean;
}
```

---

#### 2. 遗物系统

**设计目标**：增加Build多样性，创造"质变"体验

**遗物类型**：

| 类型 | 效果示例 | 稀有度 |
|-----|---------|--------|
| **伤害类** | "暴击时50%几率再次暴击" | 稀有 |
| **生存类** | "低于30%血量时获得2秒无敌" | 普通 |
| **经济类** | "金币获取+50%，但商店价格+30%" | 普通 |
| **特殊类** | "每击败10个敌人，获得1秒无敌" | 史诗 |
| **诅咒类** | "伤害+100%，但血量锁定为1" | 诅咒 |

**遗物槽位**：
- 初始1个槽位
- 最多扩展到5个槽位
- Boss掉落稀有遗物

**遗物协同**：
- 某些遗物组合触发特殊效果
- 例：[玻璃大炮] + [复活护符] = 高风险高回报

```
遗物示例：
const RELICS = [
  {
    id: 'glass_cannon',
    name: '玻璃大炮',
    description: '伤害+100%，最大生命值-50%',
    rarity: 'rare',
    effects: { damageMultiplier: 2, maxHpMultiplier: 0.5 }
  },
  {
    id: 'vampire_fang',
    name: '吸血鬼獠牙',
    description: '击杀敌人回复1点生命',
    rarity: 'uncommon',
    effects: { lifestealOnKill: 1 }
  },
  {
    id: 'critical_fury',
    name: '暴怒',
    description: '暴击时，下次攻击必定暴击',
    rarity: 'epic',
    effects: { critChain: true }
  }
];
```

#### 3. 技能系统

**设计目标**：增加主动操作深度，打破单调射击循环

**技能槽位**：
- 技能1：主动技能（按Q触发，有冷却）
- 技能2：终极技能（按E触发，需充能）

**技能类型**：

| 技能 | 效果 | 冷却 | 充能方式 |
|-----|------|------|---------|
| 🌀 冲刺闪避 | 无敌冲刺一段距离 | 3秒 | - |
| 💥 爆炸陷阱 | 放置陷阱，敌人踩中爆炸 | 8秒 | - |
| 🛡️ 护盾 | 获得3秒护盾，吸收伤害 | 15秒 | - |
| ⏰ 时间静止 | 所有敌人停止移动3秒 | - | 击杀充能 |
| ☄️ 陨石坠落 | 全屏AOE伤害 | - | 击杀充能 |

**技能获取**：
- 升级选择
- 商店购买
- Boss掉落

```
技能配置：
const SKILLS = {

  },
  time_stop: {
    name: '时间静止',
    description: '冻结所有敌人3秒',
    chargeRequired: 50,
    chargePerKill: 1
  }
};
```

### 🌟 优先级 A - 体验增强

#### 4. 分支路线系统

**设计目标**：增加游戏变化，每次游玩体验不同

**路线结构**：
```
关卡1 → 关卡2A(森林) → 关卡3A(沼泽) → 关卡4A(墓地) → BOSS(死灵法师)
      ↘ 关卡2B(熔岩) → 关卡3B(冰原) → 关卡4B(天空) → BOSS(冰霜巨龙)
```

**路线选择**：
- 每关结束后选择下一条路线
- 不同路线有不同敌人组合/环境效果
- 不同路线有不同Boss

**环境效果**：
| 地图 | 环境效果 |
|-----|---------|
| 森林 | 移动速度-10% |
| 熔岩 | 每秒受到1点火焰伤害 |
| 冰原 | 换弹速度-20% |
| 天空 | 重力降低，跳跃能力 |

---

#### 5. 随机事件系统

**设计目标**：增加惊喜和策略选择

**事件类型**：

| 事件 | 描述 | 选择 |
|-----|------|------|
| **神秘商人** | 出售稀有物品，但价格特殊 | 购买/离开 |
| **恶魔契约** | 献祭50%血量，获得强力遗物 | 接受/拒绝 |
| **精灵祝福** | 选择一项属性永久提升 | 3选1 |
| **宝箱怪** | 看起来是宝箱，实际是敌人 | 战斗/绕过 |
| **赌场** | 花费金币，随机获得奖励 | 赌博/离开 |
| **修复站** | 完全恢复生命，但失去所有金币 | 接受/拒绝 |

**触发方式**：
- 每关有概率出现1-2个事件
- 事件房间的特殊标记

#### 6. 精英敌人系统

**设计目标**：增加挑战节奏变化，提供额外奖励

**精英类型**：

| 精英 | 特点 | 奖励 |
|-----|------|------|
| 狂暴者 | 攻击+50%，血量+100% | 稀有遗物 |
| 守护者 | 护盾+召唤小怪 | 大量金币 |
| 刺客 | 隐身+高伤害 | 稀有武器 |
| 元素师 | 元素攻击 | 元素遗物 |

**精英房间**：
- 地图上标记为特殊房间
- 可选择挑战或绕过
- 挑战成功必掉稀有奖励

### 🌟 优先级 B - 内容扩展

#### 7. 永久成长系统

**设计目标**：降低单局挫败感，长期目标驱动

**成长类型**：

| 成长 | 效果 | 解锁方式 |
|-----|------|---------|
| 基础属性 | 永久+5%初始属性 | 累计击杀敌人 |
| 新武器 | 解锁新武器初始可选 | 完成成就 |
| 新角色 | 不同初始属性/技能 | 通关游戏 |
| 新遗物池 | 更多遗物可选 | 收集碎片 |

**碎片系统**：
- 每次通关获得碎片
- 碎片用于解锁永久升级
- 不同难度获得不同数量碎片

---

#### 8. 成就系统

**设计目标**：提供长期目标，增加游戏深度

**成就示例**：

| 成就 | 条件 | 奖励 |
|-----|------|------|
| 无伤通关 | 不受到任何伤害通关 | 称号+皮肤 |
| 速通大师 | 10分钟内通关 | 新角色 |
| 收藏家 | 收集50个不同遗物 | 稀有遗物解锁 |
| 元素大师 | 触发100次元素反应 | 元素遗物 |

---

#### 9. 多角色系统

**设计目标**：增加游戏可重复性

**角色设计**：

| 角色 | 特点 | 初始武器 | 被动技能 |
|-----|------|---------|---------|
| 战士 | 高血量，低射程 | 手枪 | +20%最大生命 |
| 游侠 | 高射程，低血量 | 狙击枪 | +30%射程 |
| 法师 | 元素加成 | 魔杖 | 元素效果+50% |
| 刺客 | 高暴击，高闪避 | 冲锋枪 | +15%暴击率 |

### 🌟 优先级 C - 锦上添花

#### 10. 每日挑战系统

- 每日固定种子，相同关卡配置
- 全球排行榜
- 完成挑战获得碎片奖励

#### 11. 宠物系统

- 跟随玩家的小宠物
- 自动攻击/拾取金币
- 不同宠物有不同效果

#### 12. 皮肤系统

- 玩家/武器/敌人外观
- 成就解锁
- 纯装饰，不影响数值

## 四、优先级排序

### 开发优先级

| 优先级 | 系统 | 理由 | 预计工作量 |
|--------|------|------|-----------|
| **S1** | 遗物系统 | 核心Build多样性，Roguelike灵魂 | 中 |
| **S2** | 元素系统 | 增加战斗深度，武器差异化 | 中 |
| **S3** | 技能系统 | 打破单调，增加操作深度 | 中 |
| **A1** | 精英敌人 | 增加节奏变化，提供奖励 | 低 |
| **A2** | 随机事件 | 增加惊喜，策略选择 | 低 |
| **A3** | 分支路线 | 增加可重复性 | 高 |
| **B1** | 永久成长 | 降低挫败感，长期目标 | 中 |
| **B2** | 成就系统 | 长期目标 | 低 |
| **B3** | 多角色 | 可重复性 | 中 |
| **C1** | 每日挑战 | 社区活跃度 | 低 |
| **C2** | 宠物系统 | 趣味性 | 低 |
| **C3** | 皮肤系统 | 个性化 | 低 |

### 建议实施顺序

```
第一阶段（核心体验）：
遗物系统 → 技能系统 → 精英敌人

第二阶段（内容扩展）：
元素系统 → 随机事件 → 永久成长

第三阶段（深度完善）：
分支路线 → 多角色 → 成就系统

第四阶段（锦上添花）：
每日挑战 → 宠物系统 → 皮肤系统
```
